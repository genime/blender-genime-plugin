# Blender Genime Plugin

## Description
Blender Genime Plugin is an innovative tool that integrates generative AI capabilities into Blender. This plugin enhances the creative workflow by allowing artists to generate, manipulate, and enhance animations directly within Blender using AI-powered techniques.

## Features
- Seamless integration with Blender's interface.
- AI-powered keyframe in-betweening (currently for 2D animation).
- Managed hosting (beta).

## Make3D Blender Plugin Guide
1. Request an API key by signing in on our website: [genime.art](https://genime.art)) and copy to clipboard using `Copy Blender Key` icon.
2. Ensure you have [Blender](https://www.blender.org/) installed.
3. Download the latest release of the Blender Genime Plugin from [here](https://github.com/genime/blender-genime-plugin/blob/main/genime_make_3d_plugin.py).
4. Now, start Blender and go to `Edit` -> `Preferences` -> `Add-ons` -> `⌄` (top right)-> `Install from Disk`. Select `genime_make_3d_plugin.py`.
5. Ensure it's successfully installed by searching for `Make3D` in the same Preference window. If the add-on is checked, it's installation is successful.
6. Click on the Make3D tab on the hidden pan on the right:

![blender plugin](https://github.com/user-attachments/assets/eede11f2-b15a-465f-a6f1-d625c1b2c9a4)

9. Paste your API key before using the plugin by clicking on Settings:
![screenshot](https://github.com/user-attachments/assets/2e42cd9e-1a49-47c3-94a7-cfd336b697c0)


You can also watch this demo for installation instructions: [Loom](https://www.loom.com/share/e7c0f284d4554c668ba23d3f58f87604?sid=6b654358-1102-473d-a60e-f8be810c5083).
